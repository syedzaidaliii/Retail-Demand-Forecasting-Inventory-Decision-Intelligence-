# artifacts/

Versioned model artefacts, one folder per model:

```
artifacts/<name>/model.txt          LightGBM booster
artifacts/<name>/model_config.json  feature list, objective, parameters, training window
artifacts/<name>/metadata.json      checksum, training cut-off, official holdout metrics
```

Create them with `scripts/register_model.py` (it also updates `configs/model.yaml`). The model files are small and are
committed so that CI can check every registered model for compatibility with the feature pipeline.
`artifacts/demo/` is generated by `scripts/make_demo_artifacts.py` and is not committed.
